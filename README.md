An entry for the [make.fun](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41) "One-Liner Laughs" bounty. `main.ts` (Node 22, standard library only) writes one funny line — a joke about anything at all — to `/output/entry.txt`:

> I finally cleaned my inbox. It took 4 hours, 2 coffees, and one email from 2019 that simply said 'per my last email'.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
